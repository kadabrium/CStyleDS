Included:
CVec: dynamic array/vector
CMat: 2D dynamic array/matrix
CDeq: circular array deque, doubles as stack/queue
CPrioQ: priority heap
CHMap/CHSet: compact open addressing hash map/set

Not currently supported, in order of priority:
CTSet/CTMap: binary search treemaps, node as well as arena-based
Situational data structures: CTrie, CSTable(sparse table/segment tree)
CVStr: dynamic string
CLList: linked list
